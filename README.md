# Roundy 編み図リーダー

英語の編み図 PDF を、1段ずつ日本語つきで読める Web アプリです。編みながらスマートフォンで見ることを前提にしています。

公開先: https://junpeikatayama.github.io/roundy/

PDF は端末の中だけで処理し、どこにも送信しません。URL から開くときは、ブラウザがそのサイトから直接取得します。作品と進み具合はブラウザの localStorage に保存します。

## できること

- PDF を座標から行に組み立て直し、2段組やヘッダー・フッターも考慮して読み取る
- `Rnd 1:` `Rnds 3-5:` `Row 1 (RS):` `Rows 1, 3, and 6:` `Next Row:` などの見出しを検出
- `Rnds 3-5` は3段に展開し、1段ずつ進める
- Head や Arms などのパーツ、目数、サイズ別の注記、材料や略語を分けて扱う
- PDF はファイルのほか URL からも開ける（配布元が CORS を許可している場合のみ）
- 読み取り結果を確認画面で修正（本文の編集、前とつなげる、カーソル位置で分ける、削除）
- 訳せる節だけ日本語にし、訳せない節は英語のまま残す
- 複数の作品を保存し、作品ごとに進み具合と回数カウンターを記録
- 文字サイズ、日本語と英語の主従、ダークモードの切り替え
- 画面の自動消灯の防止（Wake Lock API）
- 進捗ゲージのクリックやドラッグで好きな段へ移動
- スワイプと矢印キーでの移動、インストールとオフライン閲覧（PWA）

## 開発

ビルドは不要です。ES Modules を使うのでローカルサーバーが必要です。

```bash
npm start   # http://localhost:8000
npm test    # node --test
```

| ファイル | 役割 |
| --- | --- |
| `js/pdf-lines.js` | pdf.js のテキスト断片を、読む順の行へ組み立て直す |
| `js/pdf-url.js` | URL から開くときの入力の検証とファイル名の決定 |
| `js/parser.js` | 行をブロック（段・説明）へ解析し、段ごとのステップへ展開する |
| `js/translator.js` | 節ごとの日本語への翻訳 |
| `js/storage.js` | 作品と設定の保存 |
| `js/app.js` | 画面 |
| `knitting-dictionary.js` | 翻訳辞書（`編み物用語翻訳一覧.md` が一覧） |
| `sw.js` | オフライン用の Service Worker |

アセットを増やしたときは `sw.js` の `ASSETS` にも追加してください。

GitHub Pages は `main` ブランチのルートから公開しています。

## 既知の制限

- スキャンした PDF や画像だけの PDF は読み取れません
- URL から開けるのは、配布元が CORS を許可している PDF だけです。それ以外はダウンロードしてから開いてください
- チャート（記号図）は対象外です
- 用語は US 式を前提にしています。UK 式の編み図では `dc` などの意味が変わります
- サイズ別の表記 `5 (6, 7)` は選択せず、そのまま表示します
- 雑誌のように変則的なレイアウトでは、段の順序が崩れることがあります。確認画面で直せます
